# 第二轮：学习科学、教学设计与个体适配

## 已授权目标与范围

保留四组件和既有教学流程，扩大学习科学、教学设计与GitHub源码的取证，补上可检查、可撤回的个人适配。Claude Code负责限定目录的研究和候选，Codex审核整合；不修改真实学习账本、目标、软件配置，不运行陌生仓库代码。

## 基线触发的改动

首轮已经区分提示程度、避免人格诊断；仍缺实际提示撤除规则、同套路成功后的迁移检查、偏好与效果分账、画像假设的状态及撤回。旧画像会把拒绝类比登记为已验证失效；旧固定间隔和三段式可能压过任务/用户偏好。

## 实施顺序

1. 保留Claude基线，查论文/机构指南与三个开源项目的实际方法/代码。
2. 新增共享适配协议与teacher的教学设计/复习参考，在原画像、代码三段式、小测等拥有者文件直接消除冲突。
3. 场景演练检查帮助/独立、迁移、偏好变化、反例、数据不足、预算与权限；修复后复查相关场景。
4. 检查四技能元数据、引用、两份共享协议一致；审核差异与来源边界后备份、同步三个运行时并核对哈希。

## 成长性的实际含义

个人参数随证据更新，不自动修改全局规则；记录不等于训练，观察不等于因果试验。方法升级需候选、来源审核、行为回归、版本与备份。长期学习效果尚未验证。
