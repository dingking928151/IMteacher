# 首次引导与个人agent接入计划

**Goal:** 增量增加首次互动引导、可移植的状态接入与提醒生命周期，保留四组件与已有学习档案。

**Architecture:** using-im负责入口与首次引导；四组件分发同一组协议。用户状态仍在独立正本，宿主提供存储、调度与通知。此次实现规则与分发包，不部署云端同步服务、不创建无时间定义的提醒。

**Spec:** 本轮用户要求首次先互动、适用于Dot/Grok Bot类个人agent、跨设备记忆与提醒。现有目录、权限和长期档案保持兼容；示例内容不写入用户个人状态。
