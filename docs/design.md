# IM 技能套件：增量兼容设计

日期：2026-11-05。用户已选择“保留现有教学流程，新增三个组件”，并明确增加学业之外的人生规划与个人发展。

## 目标与范围

建立 using-im、implanner、imsupervisor，增量更新 imteacher。学业是基础，同时支持职业探索、作品项目、健康、关系、生活体验等用户选择的方向；不替用户决定理想人生。

## 方案选择

- 已选择：增量兼容。保留教学循环和已有参考文件，加入套件协作模式；独立调用 imteacher 仍可使用原有日开与多线规划。
- 未选择：立即把原有规划全部迁出。职责更纯，但会破坏旧用法。
- 不采用：把全部功能塞进一个更长的 imteacher；这会增加重复规划、上下文消耗和触发误判。

## 四个组件

| 组件 | 职责 | 产出 |
|---|---|---|
| using-im | 用户入口、识别意图、选择当轮负责人 | 当前模式、所用状态、下一步 |
| implanner | 学业与个人发展规划、探索、时间约束 | 方向假设→阶段成果→周行动→今日任务 |
| imteacher | 诊断、讲授、练习、反馈与精通验证 | 知识证据、错题、下一教学步 |
| imsupervisor | 执行对账、阻碍定位、复盘 | 已做/未做/未知、可验证调整、规划变更建议 |

一轮只保留一个负责人，只有真的需要时才交接；组件不意味着四个后台代理。

## 状态与兼容

项目内维护唯一的 IM 状态文件，索引既有教案、画像和各线总览。它只存规划与交接所需的摘要，不重抄检查点历史。已有学习档案不自动迁移、不更名。

套件模式下 planner 是计划的唯一写入者；teacher 更新知识账并返回证据；supervisor 更新对账与建议。没有 planner 的独立 imteacher 保留旧日开。现有计划已覆盖当天时，不重复排表；“继续上课”直接进入已知下一步。

先在当前工作目录制作可审核的 skills/ 源码与项目级入口，不越过目录权限直接覆盖全局安装。核实不同安装副本，提供可选安装和备份流程。

## 人生规划

先澄清本人想要的生活、不可牺牲的约束、目前资源和不确定性。方向未定时采用可撤回的小实验；长期图景是可修订假设，近期任务必须有时间预算和观察结果。保留休息、关系和无产出的体验，不将所有生活指标化。

对既定学习计划的重大改变，先解释理由、后果与取舍，再由用户确认；日内任务的普通排序按已授权范围处理。

## 文章与视频证据

Dan Koe 的文章提供方向反思与行动反馈的启发；它不充当心理诊断或教学有效性的证明。只用简短自写摘要和来源链接，不复制全文。人生反思由用户作答，AI帮助澄清，不代填价值观。

视频观点进入技能前，需区分官方页面信息、实际字幕覆盖、画面核查、独立证据、适用边界。Claude Code 负责取证/候选修改，Codex核查产物和行为；字幕受阻时报告受阻，不宣称看过。
