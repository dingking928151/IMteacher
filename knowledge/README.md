## 去重资料卡数及口径

**共 54 张去重资料卡**（18＋10＋10＋12＋4）。其中有些卡聚合同一研究线或课程的多个来源，因此不是“54 项研究”或“54 个独立项目”。口径：

- 按**规范来源身份**合并：同一来源的多个链接/版本合并在同一卡内，并逐链接标注核对状态（如同一课程的演示页＋视频＋活动页、同一论文的不同获取途径、同一项目 README 与源码、同一团队博客的上/下篇）。
- 不同研究、结论相反或撤回的内容**不合并**（如 DR-09 与 DR-10 是不同论文）。
- 近期讨论形成的原创候选议题不计入资源数。
- 仅作"备用入口"的链接随关联卡注明（未核对，不单独计数），如 DR-07 卡内的备用选片。

## 证据关键限制（摘要）

1. **视频类条目多为字幕级核对**（transcript/no-whisper 字幕＋元数据＋时间片段抽查），不等于观看画面；未观看的选片（LT-15、LC-08、DR-04 及 DR-07 卡内备用入口）均标"待核对入口"。
2. 引用等级、URL、作者名单以审核页纠正后的为准；典型例：IES Rec2 为 **Moderate**，不沿用首轮候选所写 Strong（LT-01）。
3. 学习风格匹配缺乏充分支持 **不等于** 忽略偏好、能力差异与无障碍需求（LT-04）；不编造固定番茄钟/阈值/脑型/掌握概率。
4. 结构参考类项目（LT-16…LT-18、KC-01…KC-04）均**未安装、未运行、未接入、未复制代码**；许可证按审核范围记录（OATutor 代码 MIT/内容 CC BY 4.0；jrnl GPL-3.0 未复制；WHO 手册 CC BY-NC-SA 3.0 IGO 只概述外链）。
5. ScientistTwo 是论文预印本，模型自动评审评分不等于会议录用，也不证明 IM 效果；DeepSeek 是官方设计文档＋研究原型（相关 X 文章 403 未读）；Anthropic PDF 只核可提取文本相关页，属团队自述而非对照试验（DR-10、AW-09、DR-12）。
6. 健康资料用于日常支持性交流，不提供诊断、治疗或个人运动处方；理论综述、团队经验、讲座与实证综述分清（各主题页页首注）。
