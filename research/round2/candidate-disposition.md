# Claude候选的采用与拒绝

审核日期：2026-11-06。实际审阅两份候选及evidence/repositories报告；候选未直接覆盖主源码。原件保留在 `candidates/round2/claude/`，本页是最终采用状态。

| 候选内容 | 结论 | 最终实现 |
|---|---|---|
| 帮助程度明确记录、提示后成功不算独立 | 采用其目标，重写操作 | teaching-design分五档信息量记最高帮助；根据最小必要帮助推进，后续新题无提示复验 |
| 默认检查点L2先给提示、逐层不得跳 | 拒绝 | 先完整任务与真实独立机会；能做就不额外给提示，需要示范或完整解释时不被层级仪式阻碍 |
| 连对两次后第三次必须换表征 | 拒绝机械阈值，采用诊断目的 | 看证据是否只限同套路，再按实际缺口选择变式；不设置研究未支持的N次常数 |
| 偏好与效果分轴、明确拒绝即停用 | 采用 | shared/adaptation-loop与learner-profile分列；停用不篡改以往表现，不偷偷重试 |
| verified_effective由独立作答证据驱动 | 改写 | 个人默认仍限定任务/情境；一次独立正确不证明策略的因果效果，另看代价、延迟/变式、混淆与反例 |
| 观察/假设/个人默认状态与撤回 | 采用并补足 | 添加暂停/撤回、适用范围、策略版本、反例、复审触发和可接受回退；偏好另为即时生效轴 |
| 借旧连续3天偏离>50%定画像门槛 | 拒绝 | 偏好立即记；单次事实可记观察；估时只比较可比任务，范围随实际证据修订 |
| 不做左右脑/视觉型诊断 | 采用 | 保留可接受表征偏好；任务适配不等于按所谓脑类型匹配教学 |
| GitHub三项目记录结构 | 采用有限结构，纠正来源 | 固定完整SHA与实际路径，区分OATutor代码MIT/内容CC BY4.0；未接入BKT/FSRS、不输出虚构概率 |

新增共享适配协议既约束个人参数变化，也定义全局方法升级需来源审核、实际行为回归、版本与备份。研究报告的证据等级、元数据与源码路径纠正见同目录Codex两份审核页。案例演练只表明当前文本能引导相应行为，长期教学效果需后续真实使用验证。
