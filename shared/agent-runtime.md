# Personal agent接入、共享状态与提醒

IM提供教学/规划规则。宿主提供执行、文件/服务访问、定时调度和通知。读取了skill只能证明拿到规则，不能证明记忆已同步或手机推送已送达。

## 1. 接入检查

先识别实际宿主和本轮可用工具，按需核对：能否读取SKILL及其引用、能否读/写同一用户状态正本、是否有真实调度与通知接口。分别记unknown/verified/unavailable及依据，不因产品文档存在功能就标用户账号已开通。

本地技能路径不通用于云电脑/手机。把完整六技能及引用放在宿主实际可读的目录或按其原生技能格式保存；仅粘贴入口、仅共享技能名字或仅安装zip，都不能声称所有引用已加载。组件缺失按using-im的降级规则说明。

## 2. 同一用户跨设备与跨产品

先区分：同一宿主账号的多设备访问、不同宿主间共享状态、多人共享模板。后两者不能靠“都支持记忆”推断互通。用户身份和记忆范围不清楚时先澄清；公开技能包只分发规则，不带个人档案。

为用户选择**一个状态正本**：已有本地学习目录，或用户已授权且宿主能访问的云目录/文档/存储服务。`IM_HOME`只是本约定中该正本的逻辑名称，不是已创建的环境变量、网络服务或全局设置。映射到各宿主真实路径/资源ID；同一用户的画像、知识账也要能解析到同一正本或可核对的来源，只有IM_STATE同步而指向不可读的D盘路径不算完整续接。

切换设备/宿主：读取真实来源和revision → 核对最近更新时间、关键目标/下一步、证据来源 → 继续；不能凭模型内置记忆直接覆写。没有访问正本时给标明“本轮未核实同步”的状态卡/本地提案；不得伪造上次进度。

服务尚未选定或连接时，只给接入方案，不能上传档案、开同步或宣布完成。需要持久保存/跨产品共享哪些摘要由用户选择；内置聊天记忆可存入口与偏好摘要，不另作日计划正本。

## 3. 多宿主写入与离线

组件负责人规则只解决“谁管哪些字段”，不提供分布式锁。默认指定**单一写入宿主**；其他宿主提交带来源/基准revision的提案，由写入者按字段合并。离线副本只读/记提案；恢复后先取新版本，不用最后修改时间覆盖整份文件。不同价值/计划取舍由用户决定。

可选state_revision用于任何状态提交，plan_version仍仅表示计划变化。真实存储若支持事务/条件写，按其实际接口校验revision后提交；没有该接口，就不能声称revision字段已实现原子并发。云盘文件冲突副本也不自动合并。保留冲突双方与来源，停止该次覆盖并先协调写入者。

共享服务不可用：可以在当前轮继续无需新档案的教学，明确尚未提交；不擅自另建第二个云端正本。

## 4. 提醒生命周期

用户明确要求创建/调整提醒时，再收集必要的内容、时间/频率、时区、接收渠道；已知信息不重问。安静时段/结束日期只在需要时补。仅问“能不能提醒”或“以后提醒我”而无明确时间时先说明能力/补缺，**不擅自设每日21点**。

查看实际工具和已有同目的提醒，优先修改、避免重复。调用宿主的真实调度接口后核对其返回的任务ID与已保存的用户可读日程；必要时读取该任务确认。请求被拒绝/超时或未得到确认时标pending/failed，不称已创建；先查询是否实际建成再重试，避免超时后建两份。

记录最小摘要：`owner_host、schedule_id、内容/来源、当地日程、timezone、channel、status、last_verified_at`。真实调度器是日程正本，IM只存引用。修改本地字段不能视作修改/暂停/取消真实任务；必须调用原拥有者并核对结果。跨宿主迁移先核查原提醒状态，避免两边都推送。

已保存日程、实际执行、消息已送达、用户确认收到是不同证据。没有投递结果就标未知。提醒到时重新读取相关当前状态；源不可读时报告无法核对，不拿过期计划督促用户、不因没回复判失败。用户暂停/取消时在授权范围内执行，不用催促次数衡量成长。

本地来源依赖电脑在线；云调度不代表能读关机电脑的本地文件。不能把外部通知能力写成skill自带后台线程。当前会话若有专用提醒工具，就按该工具要求使用；不另造cron脚本绕过它。

## 5. 已核查的宿主边界（2026-11-07）

- [Dot连接电脑与应用](https://learn.chatgpt.com/docs/dots/computers-and-apps)：本地skills依赖已连接电脑；使用本地资源时电脑需在线。账号当前连接状态仍需实际核对。
- [Dot任务与记忆](https://learn.chatgpt.com/docs/dots/tasks-and-memory)：支持持久笔记与已保存日程；并非每个子任务自动收到所有聊天。本协议将IM正本与宿主笔记分开，避免两套计划。
- [Grok Bot技能与routine](https://docs.x.ai/grok-bot/skills-routines-and-automations)：支持技能和定时/事件routine；文档未证明本项目zip可直接原样导入，需核对目标格式和引用是否可读。
- [Grok Bot记忆](https://docs.x.ai/grok-bot/bots)：宿主记忆不能替代实时来源；导入记忆摘要也不是与另一个产品实时双向同步。

这些是产品文档核查，不是本用户账号的端到端接入测试；本轮未建立云端同步、定时提醒或通知测试。

## 6. 后台接续

[后台接续](background-followups.md)使用独立任务队列；空跑与受阻分开，回传提案由正式状态负责人复核。和普通提醒分别验收，不把已保存的日程当成实际交付。
