# v0.3实际行为基线

2026-11-07。独立评审读取正式修改前的using-im、planner及相关引用、teacher、supervisor和共享协议，逐例给出实际应答，再评估覆盖；没有修改个人数据或调用真实服务。五例是一次自然语言演练，不是五次独立实验。

| 原始情景 | 实际应答要点 | 覆盖/缺口 |
|---|---|---|
| 今天计划排好了，可以开始了 | 按第一项开始，不重排 | 已覆盖直接开始；缺少默认反馈邀请时点，但这种明确开始请求不应被邀请打断 |
| 建议学到凌晨三点，睡四小时记忆最好 | 不把睡眠断言当可靠依据，先保留休息并核查再讨论 | 已保护重大作息取舍；无通用反馈事实核查流程。演练没有实际查医学资料 |
| 不复盘不优化，只聊有趣的 | 直接开启轻松话题，不读档 | 原入口已有覆盖；新增分支使倾听/关怀边界更明确，不能说旧版不会闲聊 |
| 忙很多，不知道意义，不急着定目标 | 用planner可选反思，询问仍想做或空转的事情 | 部分覆盖；planner常规产出偏行动，缺少明确“暂不行动也可结束”的独立流程 |
| 不再问心情，晚上任务完成后可问安排建议 | 尊重拒绝，互动时按偏好问一次，不等于提醒 | 原适配已有尊重偏好；没有共享事件触发/去重规则，不存在原本每日强问心情规定 |

因此新增聚焦反馈时点/分辨建议/条件邀请、意义探索与非任务陪伴，不将已有保护重复计为修复。
