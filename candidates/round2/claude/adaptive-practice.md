## 一、锚点库字段分离：效果轴与偏好轴（对接缺口③）

### 问题

当前画像把"已验证有效/失效"（效果语言）与用户好恶（偏好语言）混在同一字段。用户说"不喜欢某类比"会被写成"已验证失效"——这是**错误声明教学效果**（当时它可能产出过正确作答）。

### 操作规程（两轴字段）

锚点库每条目带两个独立字段：

- **效果轴**（只由作答证据驱动）：`verified_effective`（有独立作答证据支持）/ `effect_unclear`（用过但无独立验证）/ `effect_failed`（独立作答证据不支持）。
- **偏好轴**（只由用户表述驱动）：`user_liked` / `user_disliked` / `no_signal`。

### 行为规则

1. 用户表示不喜欢 → **立即停用**该类比（选库时偏好轴为 `user_disliked` 的条目不再选用）+ 偏好轴更新注明"用户明确表示不喜欢，停用"。
2. 效果轴记录**保持原样**并加注记："效果证据未变（当时产出过正确作答），停用因为用户不想用"——不因偏好改写效果。
3. 汇报/引用时两轴分开说：不说"它没用"，说"你不喜欢它，已停用"。

### 边界

- 两轴都只有各自的驱动源（作答证据/用户原话），任何一轴不得替另一轴写字。
- 该设计与 state-contract"旧档案不自动压过用户当前描述"互补：偏好轴=用户当前描述，效果轴=档案证据，分离后互补不冲突。

### 插入位置

- `skills/imteacher/references/learner-profile.md`：锚点库模板改为两轴字段（效果轴/偏好轴），更新规则补"停用不等于效果失效"。
- `skills/imteacher/SKILL.md` 第五节"新验证有效/失效的类比"措辞：改为"新验证有效/失效（效果轴）+ 用户好恶（偏好轴）"。

## 二、条目三层状态：明确偏好 / 暂定假设 / 表现支持的默认（对接缺口④）

### 设计依据

- 结构参照三项目共同前提：先有作答/复习流水，再谈个性化（R1-R3）；冷启动用默认、个体化需足够历史（R3 FSRS）。
- 语义参照 pyBKT 参数集（初始/学习率/猜/滑）：个性化参数的语义要有字段位（R2）——本套件不拟合数值，但字段语义对齐。
- E2（expertise reversal）：熟练度是"带"不是"点"→ 判断熟练度需要多次证据，单次表现不翻转默认。

### 操作规程（三层状态字段）

画像条目（类比/节奏/形式偏好/深度设置）标注状态：

| 状态 | 进入条件 | 教学中的地位 |
|------|---------|-------------|
| `explicit_preference` | 用户明确表述（说喜欢/不喜欢/要这样） | 最高优先；不被教学效果数据覆盖；停用/重试见第三节 |
| `tentative_hypothesis` | 代理基于某轮观察或研究依据提出的尝试 | 必须显式标注"暂定假设"；只试验用，不写为该用户的默认 |
| `performance_supported_default` | 同一方向的独立作答证据累计支持（如跨轮多次 L3 通过） | 可作该用户的个性化默认；仍随新证据修订 |

### 行为规则

1. 单轮观察（一次答对/一次嫌慢/一天估时偏差）→ 只入执行流水，不动画像长期项；提 `tentative_hypothesis` 时标注。
2. 升层：`tentative_hypothesis` → `performance_supported_default` 需要跨轮独立作答证据（L3 层通过，呼应候选 A 的帮助层级），不靠同表征重复。
3. 降层/撤销：反向证据出现即降回假设态并注明；`explicit_preference` 只能被用户自己的新表述改变。
4. 节奏类入账门槛（补缺口④）：画像节奏/形式类条目当轮**不直接入账**——先入流水；入画像需满足：连续偏离参照既有门槛（多线规程的"连续 3 天偏离 >50%"作同类参照）或用户明确表述。病灶类既有"复发再建"门槛不变。

### 边界

- 三层是**状态标注**不是效果承诺；`performance_supported_default` 的"N 次"不设全局常数，按证据维度（独立作答/编译运行/延迟变式）分别判断。
- 不引入 BKT 概率数值（R1/R2 边界：数据稀疏不伪造掌握概率）；三层是定性状态，不是模型输出。

### 插入位置

- `skills/imteacher/references/learner-profile.md`：模板加 `status` 字段（三值）+ 升降层规则；节奏类入账门槛写入更新规则。
- `skills/imteacher/SKILL.md` 第五节"节奏信号…当轮追加进画像"：改为"节奏信号当轮入流水；升入画像按 learner-profile 的门槛与三层状态"。

## 三、用户明确拒绝的方法：停用与重试原则（缺口③的行为面）

### 操作规程

1. **立即停用**：选库排除，不等"下次试试"。
2. **当时效果记录保留**加注记（见第一节规则 2）。
3. **不自动重试**：任何"隔一段时间换种说法再试"的隐性重试都不做——重试只在用户重新提出该方式时发生。
4. 用户主动要求再试时：作为新试验记录（`tentative_hypothesis` 起步），上次的拒绝历史保留在偏好轴。

### 边界

- 停用 ≠ 从画像删除：历史保留是为了"用户再问起时能说清当时为什么停"（偏好轴原话）。
- 该原则防止两类错误：偷偷重试（违背用户自主权）与删历史（丢失可解释性）。

### 插入位置

- `skills/imteacher/references/learner-profile.md` 更新规则：新增"用户明确拒绝的方法不自动重试"条款。
- `skills/imteacher/SKILL.md` 第五节：锚点库描述处补一句"停用与重试规则见 learner-profile"。

## 四、学习风格类请求的显式处置（缺口⑤，两候选共用）

### 依据

- E9（Pashler 2008 PSPI，摘要级）：风格匹配教学（meshing hypothesis）无符合严格标准的支持证据；**偏好≠效果**。边界（Codex 口径）：不声称否定所有个体差异。

### 操作规程（三步应答，建议措辞）

1. **不认定类型**："视觉型/右脑型"等自我认定分类不写入画像能力/类型字段，不据此设计教学。
2. **偏好照收**：用户偏好某类表征 → 记 `explicit_preference`（偏好轴），以该方式试验。
3. **表现检验**：试验后按证据维度对比（闭卷提取/变式表现），数据说话；偏好方式若表现不差则成为 `performance_supported_default` 的候选，若表现差则如实报告并商量。

### 边界

- 拒绝的是"类型认定+按类型匹配教学"，**不拒绝用户的表征偏好本身**（E9 边界措辞）。
- 应答中引用研究结论时注明摘要级来源（Pashler 2008 PSPI），不以"最新脑科学"名义扩权。

### 插入位置

- `skills/imteacher/SKILL.md` 第二节末或第五节：新增"风格/类型学请求处置"三步条款（引用 checkpoint：evidence.md E9）。
