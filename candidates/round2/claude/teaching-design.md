## 一、帮助层级四级序列（对接缺口①）

### 设计依据

- 序列原型：IES 2007 Rec 2"例题随熟练度渐退"（E1，全文级）+ Atkinson/Renkl/Merrill 2003 渐退实验（E3，摘要级）。
- 结构参照：OATutor 提示依赖链与子提示 0.5/1 分级（R1）——帮助程度在事件层分级记录。
- 现有衔接：三段式（SKILL.md 第三节）已经是天然的 L0→L2 阶梯，缺的是**显式层级标记与升降级规则**，不另起炉灶。

### 操作规程（四级）

| 层级 | 内容 | 对应现有机制 |
|------|------|-------------|
| L0 全解 | 完整推导/参考代码逐行（首讲精细块） | 三段式段一 |
| L1 骨架 | 关键步留空，学生补全 | 三段式段二填空 |
| L2 锚点 | 只给方向性提示，不给步骤（"先查边界条件"） | 现无——新增 |
| L3 独立 | 无提示作答，唯一可记"独立作答"证据的层 | 检查点/迷你验证关 |

### 行为规则（建议措辞）

1. **默认起点**：新概念首次检查点从 L2 起；L2 失败降 L1，L1 失败降 L0 重讲对应块。降级逐层，不跳。
2. **升级触发（关键反向规则）**：同考点连续两次 L0/L1 通过 → 下一轮必须以 L2 或 L3 复验同考点。这是"带提示会了≠会了"（baseline 情境①）的显式防线：**L0/L1 的通过不写入独立作答证据，只写帮助层级**。
3. **记录**：检查点流水每题标注所用层级（L0-L3）；证据维度联动 state-contract——L3 通过才记"无提示独立作答"。
4. **出池联动**：错题池出池复验一律 L3（跨时间+换问法已有，补"无提示"为默认条件，现行做法本就如此，只是显式化）。

### 边界（写进候选，防夸大）

- 不声称 fading 提升学习效果：E3 为单实验单领域，E1 是 WWC 评级非效应量。此序列是**组织作答的框架**，不是效果承诺。
- 升降级按表现判断，不设"第 N 题必须换层"的题数常数。
- 学习者明确偏好优先：首讲精细块（全推导一封消息）= L0 起点偏好，与本序列不冲突——序列管**验收**，不接管讲。

### 插入位置

- `skills/imteacher/SKILL.md` 第一节教学循环"检查点（3-8 题…）"行：补"检查点默认 L2 起、连续两次带提示通过后须 L2/L3 复验"一句。
- `skills/imteacher/references/teaching-loop.md`：新增"帮助层级四级"小节（四级定义+升降级规则+记录格式）。
- `skills/imteacher/references/checkpoint-bank.md`：题型标注加一列"默认帮助层级"；新增"锚点提示"题型示例。
- `shared/state-contract.md` 证据表：帮助程度列增加 L0-L3 值域约定（仅约定，不改表结构）。

## 二、同表征重复正确的主动升级（对接缺口②）

### 设计依据

- 变式失败先辨析败在哪层：选法/符号/执行/迁移（Codex 审阅口径，baseline 情境②修正版）。
- 边界依据：Brunmair & Richter 2019——交错收益在数学任务上小且依赖相似性（E6）→ 换表征的目的是**检验表征绑定**，不承诺收益。

### 操作规程

1. **表征账**：出检查点/回顾题时，查该考点已通过题目的表征集合（换问法记录散在留痕里，现无汇总视图——建议出题前扫一遍该考点历史题）。
2. **升级规则**：同考点**同表征**连续通过 2 次后，第 3 次必须换表征；换法按四层选：
   - 选法层：同概念换适用情境（考"什么时候用这个方法"）
   - 符号层：换记号/约定（考记号是否真绑定而非背形）
   - 执行层：换数值/结构微调（考过程独立复现）
   - 迁移层：组合进未见过的小情境（考迁移）
   优先动选法层（最便宜、最能暴露模式匹配），迁移层留给换问法出池复验或小测。
3. **变式失败分流**：按四层辨析失败位置再选处理（选法类给对照例、符号类对齐约定、执行类拆步骤、迁移类才重讲根因），**不自动判概念类**——与第二节错误分类学表对齐。
4. **不与新概念首学混合**：换表征发生在已通过考点的复验/小测场景，不打断首次学习块（E6 边界的操作化）。

### 边界

- 不承诺换表征提升保持/迁移（E6：数学任务收益小）；其直接作用是**暴露模式匹配**，效果由表现检验。
- "连续 2 次"是观察触发器不是效果阈值——触发后换不换、换哪层仍按四层判断。

### 插入位置

- `skills/imteacher/references/checkpoint-bank.md` 出题原则：新增一条"同表征连过 2 次后必须换表征（四层选法），变式失败先辨析败在哪层"。
- `skills/imteacher/SKILL.md` 第二节错误分类学：概念类行的处理改写为先辨析"选法/符号/执行/迁移"哪层失败（对应 Codex 审阅意见）。
- `skills/imteacher/references/quiz-and-review.md`：错题池出池"换问法"补一句"换问法优先动选法/符号层"。
