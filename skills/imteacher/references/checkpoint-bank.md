# 检查点题型库

每个检查点通常3–8题，依目标、诊断价值和预算选择；不足时可拆分，不为数量加题。优先核心解释与应用，明确尚未覆盖什么；不把同场换数字自动视为迁移或延迟保持。

## 题型

| 题型 | 考什么 | 例 |
|------|--------|-----|
| 填空 | 概念骨架、术语 | "目录里存的是'文件名 → ___号'的映射" |
| 选择 | 易混淆对、排除错项 | "cp 后两文件 inode：A 相同 B 不同" |
| 手算 | 核心操作能不能做 | 给 5 个区间手算贪心选择 |
| 默写/复述 | 流程、因果链 | "四层链条默写""一句话复述引用计数" |
| 情景判断 | 策略应用 | "卡 50 分钟怎么办，三步" |
| 实敲预测 | 预测-对账纪律 | "预测 ls/cd/cat 各什么命运再跑" |
| 纠错 | 给错误代码找茬 | "这段 14 处错误自己过一遍清单" |
| 反例构造 | 概念边界 | "举一个按长度排序失败的例子" |
| 变式迁移 | 修复验证 | "nn.Linear(300,88) 的 W shape？" |
| 对比题 | 两个概念的关系 | "DP vs 贪心，什么时候用谁" |
| 桥接题 | 新旧知识连线 | "Bash 的 | 和 C 的 pipe() 什么关系" |

## 出题原则

1. **不考背诵考推导**：能推导的（shape、权限八进制）不给背的（不给口诀让背数字）
2. **含一道"为什么"**：防止只记结论不懂理由
3. **含一道接近实战的**：情景判断/信号识别/排查顺序
4. **高风险错误优先**：按关键前置、独立性、间隔与预算选变式。提示后对不计独立连对；归档条件见 [回顾规程](quiz-and-review.md)，归档不等于永久掌握
5. **量力而行**：独立表现稳定时先减少多余提示或变相关条件，不直接叠题量；重复卡住先诊断前置/方法/表征。帮助分级和撤除见 [教学设计](teaching-design.md)，排题见 [练习调度](adaptive-practice.md)

## 判定标准

- ✅：意思完整到位（措辞不完美可后续精确一格）
- 半对：方向对、机制/表述缺——补讲 + 给标准表述
- ❌：方向反/答非所问——按错误分类学处理
- 漏答：可能题意没懂——先确认是否理解题意，再判定
