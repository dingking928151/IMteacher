# 练习与复习调度：透明规则、真实证据

新任务、续课回顾、提示后成功或同套路连对时使用。复习服务于当前学习目标，计入总预算；不因有到期项就自动追加作业。

## 最小数据

复用现有知识账/错题池：`任务ID/KC | 日期 | 问法/表征 | 结果与来源 | 最高帮助 | 独立性 | 实际间隔 | 下次检查原因`。编译/运行/OJ单独记。未知间隔、未见答案、只有“看懂了”都标未知，不补造评分。

可在诊断价值高时请用户先估把握/预计耗时，再比实际；不每题追问信心，也不把信心与正确率合成所谓脑能力值。先前没有预测就不事后代填。

## 当次如何选题

1. 看下一目标依赖什么；优先关键前置缺口与独立失败，复用近期有效证据以免重考已会内容。
2. 看证据缺什么：只有示范/提示后成功 → 新题独立；只有同套路成功 → 改相关表征/条件并问方法选择；只有即时成功 → 留一次延迟检查；已经延迟变式成功 → 适度减少该项占用。
3. 多个候选冲突时，综合依赖风险、已确认截止日、间隔和本次预算，说明先选哪一项即可。不要用没有训练的概率数字制造精确感。
4. 基础不稳先聚焦学习；有必要的基础后才交错易混淆类型。随机打散无关任务并非更专业。

## 结果到下一步

| 实际表现 | 处理与复查 |
|---|---|
| 提示后答对/刚看完示范的同题对 | 记录最高帮助；选未泄露的新题撤提示，不累计独立连对 |
| 独立失败或半对 | 诊断后纠正，安排合适的新尝试；后续检查更近只是可调策略，不用重复刷同题替代诊断 |
| 当次独立正确 | 支持本题表现；换相关问法/情境、留延迟检查，逐步延长复查窗口 |
| 延迟/变式独立正确 | 更新该KC范围的保持/迁移证据，减少不必要重复，继续关注后续反例 |
| 缺席/未回复/没有产物 | 结果未知；到期重排，不判遗忘或未完成 |

无数据时 D+1/D+3/D+7 可以作人工暂定窗口，不是最优算法；实际日期结合用户预算和目标保持期决定。已有安排被证据推翻时写明原因，保留原结果。具体归档与小测见 [回顾规程](quiz-and-review.md)。

## 两个例子

- 昨天在方法提示后写出 Prim，今天有15分钟：优先一项无提示“为何从跨集合边选最小”的解释或小图追踪，留作答和批改时间；不能把昨天视作独立通关、今天再加15分钟之外的完整代码作业。
- 一周后用新图独立追踪正确、但代码编译未见：分别记保持/新图应用已见，运行未知；不以缺运行否定概念证据，也不凭概念正确写成OJ通过。

## 借鉴模型，不冒充实现

[pyBKT固定提交](https://github.com/CAHLR/pyBKT/tree/0f4ea412e18f6bcbd396fdf2be68fdd43aebebb6) 的 `Model.fit/predict/evaluate` 与 `data_helper.convert_data` 展示知识点、顺序、作答数据和模型评估的重要性。本套件借鉴结构化轨迹，**没有运行BKT、拟合参数或校准概率**；“掌握度92%”不能从聊天印象中生成。

[FSRS4Anki固定提交](https://github.com/open-spaced-repetition/fsrs4anki/tree/ff7c85cee735472d1c9cec0b9252d184087f74d8) 的调度源码根据状态、时间及评分算间隔，并有默认参数；个性化优化与使用默认调度是不同步骤。本套件未接入其调度器，以上窗口只是人工规则，不得称已运行FSRS。将来真接工具时需确认时间/评分语义、历史数据质量、参数来源、版本与评估结果，明确默认参数与个性化拟合。卡片回忆调度不自动等价复杂解题能力。

## 科学边界

[Agarwal等(2021)全文](https://pdf.poojaagarwal.com/Agarwal_etal_2021_EDPR.pdf) 支持课堂情境中的提取练习，但不指定本人的最佳间隔/题量；[IES实践指南](https://ies.ed.gov/ncee/WWC/PracticeGuide/1) 提供间隔、提取与示例等建议。具体优先级、窗口和状态是本套件的待检验设计，不能由“脑科学”三个字直接推出。
