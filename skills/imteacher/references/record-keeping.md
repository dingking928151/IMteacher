# 留痕系统 · 文件模板与更新时机

留痕 = 跨会话续接的唯一载体。学习者可以换会话、换时间回来，
新会话读留痕即可无缝续教。**每轮批改必须同步更新留痕**。

## 文件位置与命名

- 放在学习资料同级目录，如 `24周教案/学习留痕_W8-W16/00_学习进度总览_W8.md`
- 一个教学阶段（一周/一单元）一个文件；阶段间可互链

## 模板结构

```markdown
# W? 学习留痕 · 进度总览

> 开始日期：YYYY-MM-DD
> 教学方式：IMteacher（teach-check-continue + 代码三段式 + 实敲模式）
> 目标：一句话写明本单元毕业标准

---

## 一、知识地图

### 主线
- [ ] 1. 知识点 A（一句话内容）★核心★ 标注
- [ ] 2. 知识点 B

### 副线
- [ ] A. 副线内容 ← 教学顺序/备注
- ~~X. 已裁定搁置项~~ —— 用户裁定：搁置原因（裁定保留在案，不删）

## 二、资料清单与对账（资源 × 看哪里 × 回来对什么账）

- PPT/讲义考点清单：开课时从用户提供的教案/PPT 提取考点建账，覆盖一个勾一个（每周小测出题源）

## 三、前置对账与模式记录
- 已确认的前置能力
- 实敲/纸面模式及切换记录

## 四、检查点流水（每轮追加）

### 检查点 N（知识点名）—— 日期
- 逐题结果：✅/❌/半对 + 学习者原答案摘要 + 错误分析 + 最高帮助/独立性 + 证据来源
- 处理：重讲要点 / 读法 / 迷你验证 / 勘误
- 判定：通关 → 下一站

## 五、勘误记录（教案/资料不严谨处，含修正版）

## 六、收官盘点
- 板块 × 状态总表
- 剩余实做项（与教学线分开记账）
- 隐藏收获（调试工具/论文读法等 meta 技能）

## 七、错题池（滚动回顾出题源）
- 每条：任务/KC | 日期/问法 | 错法及来源 | 最高帮助/独立性 | 实际间隔 | 下次变式与理由
- 暂归档：按 [回顾规程](quiz-and-review.md) 检查跨时间、换问法、无关键提示；提示后对不累计独立成功，同场重复不算延迟，归档不等于永久掌握

## 八、每周小测成绩单
- 日期 | 逐题对错 | 薄弱点 | 补测安排
```

## 更新时机（缺一不可）

| 时机 | 更新什么 |
|------|---------|
| 开单元 | 知识地图 + 资料清单 + PPT/讲义考点清单 + 模式记录 |
| 每轮批改 | 检查点流水（原答案 + 判定 + 处理）——**学习者原话要记**，错误分析靠它 |
| 发现教案不严谨 | 勘误记录 |
| 学习者裁定搁置/删除 | 在知识地图上划线保留裁定与原因，不物理删除 |
| 知识点/副线通关 | 日期 + 任务范围 + 独立解释/应用/运行等分别记录；修错数只描述修订，不单独作为通关依据 |
| 单元收官 | 收官盘点 + 剩余实做项 |
| 每次滚动回顾后 | 回顾一行（抽了什么/对错/出池没）+ 错题池计数 |
| 每周小测后 | 小测成绩单 + 错题池更新 |

## 新会话续接流程

1. 读留痕文件（老会话也可能要读：上下文压缩后留痕是 ground truth）
2. 沿已通关证据继续，不重开全课；相关证据过时与否看实际间隔/新反例，必要时做一个有目的的保持/迁移检查
3. 若留痕与学习者当前报告冲突，核对日期及是否有新进展，分别记录用户自述与可见证据；不自动让旧档案压过当前报告
4. 检查点流水中"高发错误"名单决定新检查点的重复覆盖点
5. 续课按关键前置、独立性、延迟和预算选择少量回顾；D+1/D+3/D+7仅为可调的冷启动窗口，不把到期项全部强塞进本次

## 语气与隐私

- 留痕是教学档案，记录错误分析对事不对人；不用评价性语言（"粗心""笨"），
  只记现象与根因（"第 2 次仍混淆 fd 与 inode，根因：三层楼未分层"）

## 独立模式的反馈元数据

按 [共享状态](state-contract.md) 的“独立teacher的反馈落点”在既有TMP的“互动元数据”节维护唯一feedback_offered_on和画像指针，不按教学线复制日期。suite只用IM_STATE.interaction，TMP留指针；真实邀请后才写。无权限/不愿保存时仅本轮去重，原学习留痕授权不自动扩张为保存私密反思/聊天。
