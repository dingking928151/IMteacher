# 每日反馈与对话选择

## 何时邀请

默认在当天第一次制定好可执行日计划后，末尾简短邀请一次：“对这份安排有没有想调整的地方？愿意的话说一句，也可以先开始。”这是本套件的可调整默认，不是研究证明的最佳频率；用户可改为任务结束后、周末、主动提出才讨论，或关闭。仅改周/年度方向、续课、闲聊不触发；当日改计划不再自动问。用户说“直接开始/别问”时直接执行，不能为了邀请打断。

先查同一画像中的明确偏好和 interaction.feedback_offered_on；实际发出邀请后才标当地日期，不能预记、从updated_at推断、或以“有反馈吗”反复追问。用户主动反馈不限次数，跨日也不补交问卷；跳过/无回复不算失败。其他触发点仅在用户偏好明确时采用，任务结束须确实发生或用户报告，不凭未回复判断。

有状态写入权限时由当前唯一写入者记 interaction 的最小元数据。没有正本访问则只在本轮上下文去重，并说明跨设备去重未核实；不为一句聊天反馈强制建档。相同日期与时区的跨会话依赖同一正本和单一写入者，本文件不是分布式锁。反馈偏好指向同一适配画像，不另建重复档案；原话默认不持久保存。

## 如何判断建议

先分清用户是在表达什么，再回应；不要把“需要判断”用成审查用户喜好的理由。

| 内容 | 处理 |
|---|---|
| 明确偏好、拒绝、可用时间、身心承受限制 | 当下尊重，更新已授权的个人偏好；不要求先试到有效才允许拒绝 |
| 可核对的事实或因果判断 | 核实可靠来源，区分事实/推测/未知；涉及健康等高风险内容现场查权威资料，不能为迎合而认同 |
| 学习、执行或规划方法 | 看与目标/前置/预算的匹配、代价与已有反例；有分歧解释具体原因，可提出小范围可撤回试验 |
| 人生价值与方向 | 由用户决定，协助理解选项与后果，不评成正确/不合格，不从一次情绪推断最终价值 |

回应采用自然语言：准确接住建议 → 赞同、部分采用或有保留的具体理由 → 当下怎么做/可选试用及何时回看。简单偏好一句落实即可，不为每句话写辩论。事实与价值混合时分别回应，例如尊重想提高效率，但不采纳未经支持的睡眠断言。提出替代方案，不能据此直接覆盖长期承诺。

## 反馈如何生效

教学方法交teacher；计划变更交planner；执行条件与阻碍交supervisor；意义/经历交reflect；聊天方式与关怀交companion。可以同轮顺序交接，只保留一个计划正本。未实际改写就说建议/待处理，不能说已经保存。

个人调整按 [适配流程](adaptation-loop.md) 记录必要的情境、证据、负担、反例和复审条件。明确偏好即时生效；策略效果仍需观察。用户反馈不直接重写全局SKILL；全局升级另走候选—审核—验证—备份。合理反对也要保留用户选择与修正助手的入口。

## 何时聊深一点，何时只聊天

不固定把反馈、心情检查、反思、人生规划全部塞在每日结束。每轮最多一个相关的可选开口，服从用户给的时间和当前意愿；已给反馈邀请时不再自动叠加反思/健康问题，明确提出的多个请求按顺序处理。

- 用户想核对做了什么：supervisor；想知道经历的意义或探索其他活法：reflect；要把想法落为路线与时间承诺：planner。
- 用户只想轻松交流/倾听：companion，允许没有结论和行动。不给每次聊天找“成长价值”。
- 出现重复阻碍可邀请探讨，但不强推深层原因；对方拒绝就回到原任务或结束。休息、关系、兴趣和聊天无需折算为学习产量。

## 方法来源

[Ryan与Deci（2000）](https://www.selfdeterminationtheory.org/SDT/documents/2000_RyanDeci_SDT.pdf) 的理论综述讨论选择、理解感受、有意义的理由与自主支持。可用于检查对话是否施压；它没有研究本套件或每日反馈频率，也不表示所有必要责任都必须让人感兴趣才值得做。本文的分类与邀请规则是应用设计。

[Hattie与Timperley（2007）](https://conselhopedagogico.tecnico.ulisboa.pt/files/sites/32/hattie-and-timperley-2007.pdf) 区分任务、过程、自我调节与对人本身的反馈，提示应回应具体信息而非人格评价。[Nicol与Macfarlane-Dick的讨论稿（2004）](https://www.villanova.edu/content/dam/villanova/vital/vitalinks/7principlesofgoodfeedback04.pdf) 强调学习者解释反馈、对话与回应机会。这里将其借鉴为“说明是否采纳与去向”，不要求每条建议都生成行动；可保持、暂挂或说明还缺什么。这些课堂反馈资料未直接验证用户向AI反馈的效果或频率，2004稿不冒称已精读2006期刊正文。
