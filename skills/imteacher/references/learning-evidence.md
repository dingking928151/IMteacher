# 学习方法：来源与应用边界

Barbara Oakley 的 [Learning how to learn](https://www.youtube.com/watch?v=O96fE1E-rf8) 在约14:00–17:10讨论熟悉感与提取/练习。本次 Claude Code取得字幕，Codex抽查原VTT；未据此声称看过幻灯片。

应用：看完一段先合上材料解释或解一道变式，再根据回答决定是否推进；必要时延迟重做。视频时长和笔记量记录为投入，不直接当能力证据。

独立研究来源：[Roediger 与 Karpicke，2006，Test-Enhanced Learning](https://journals.sagepub.com/doi/10.1111/j.1467-9280.2006.01693.x)，研究了学习文本后的提取测试与保持。它支持在相应条件下考虑提取练习；不证明本技能所有步骤、固定题数、两连出池、代码迁移或特定间隔都最优。

讲座的专注/发散类比可帮助理解休息与换方法，不作为严格大脑状态诊断。番茄钟是可选时间管理工具，长度随任务与学习者条件调整。

旧版主文中的 Dubinsky 2024、Brod 2021 等简称没有随附完整可核实条目；当前保留的讲授偏好按已形成的教学设计使用，不将这些简称视为本轮已查证研究或所有人通用的因果结论。
