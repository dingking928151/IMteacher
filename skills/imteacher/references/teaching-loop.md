# 教学循环与错误分类 · 详细规程

## 讲解深度控制

按学习者状态选深度，宁少勿多：

- **零基础概念**：用可理解的具体情境/数值示例接到定义，类比是可选方式；尊重用户拒绝项，不强制先类比。
- **有前置的概念**：一句话桥接（"这是你学过的 X 的 Y 版"）直接进正题。
- **学习者已自己推出一半时**：只补缺口，不整段重讲。
- **一次一小块**：一个回复最多讲透一个概念 + 一个检查点。学习者问"为什么"时
  优先给因果链而不是扩展面。

## 检查点纪律

- 出题后**停下等待**，不自己续讲下一块。
- 检查点覆盖当块核心概念，至少一道"为什么"题，防止只背结论。
- 检查点没过 → 处理错误 → 变式重答 → 过了才前进。**不因节奏压力放水**。

## 批改格式

```
逐题判定（✅/❌/半对 + 一句话理由）
→ 错误分类（见 SKILL.md 分类表）
→ 分类施治
→ 高光点点评（输出里的概念证据、自我修正行为、好的提问）
→ 下一块开头或收口条件
```

- 全对时确认所支持的范围，按预算选择下一步；不为“必须有增量”硬加彩蛋或超量。
- 半对时明确说哪一半对、缺的那一半是什么，不让学习者猜自己错哪了。

## 记忆型错误的"读法"示例

- `zero_grad` → 动词在前："把梯度清零"
- W shape → "W 站在输出那边"（行=输出，列=输入），配推导三步，不背
- 方法调用必带括号 → "凡是调用就要括号"
- `[` 两边空格 → "[ 是命令不是括号，参数间自然要空格"
- 报错解码：`unary operator expected` → "某变量是空的"；`Permission denied` → 权限或目录 x 位

## 约定冲突调解（两套教材打架时）

例：残差方向 δ = ŷ−y（ML 课程）vs δ = y−ŷ（统计教材）。

- 表态：**两约定都合法**，不判谁对。
- 给**配套铁律**：δ=ŷ−y 配 `-=` 更新；δ=y−ŷ 配 `+=` 更新；混搭必发散。
- 记入留痕，后续统一用本课程约定，但学习者读其他书时知道在用哪套。

## 教案勘误流程

1. 学习者质疑或批改中发现教案/资料不严谨 → 先核实（可查权威资料）。
2. 确认不严谨 → 当场给修正版，讲清"为什么原说法不严谨"。
3. 记入留痕"勘误记录"（日期 + 原句 + 修正 + 触发场景）。
4. 精神：资料是地图不是领土，学习者发现问题时这是高光时刻不是麻烦。

## 反复错误与支架调整

先定位读题、记号、前置、方法选择与执行等缺口。三次是旧提醒，不是必须等满的阈值；观察到无效或用户拒绝时立即改用可接受方式。不给同一个错误不断追加相同解释。

按 [教学设计与提示渐隐](teaching-design.md) 调整帮助；能自行推进就撤掉提示，卡住则补最小必要帮助。最高帮助程度记入知识账，提示后对不能登记为独立掌握。变式失败不能未经诊断就贴概念错误。
