# 教学设计：目标、支架与迁移

在新单元、重复卡住、需决定示范/提示强度时使用；简单概念问答不强制整张设计表。保留用户既有中文、完整题目先思考和完整首讲等偏好。

## 1. 从表现目标倒推

用一句可观察表现写目标，例如“能在含重复值的有序数组中独立找到第一次出现位置，并说明循环不变式”。拆2–4个必要知识点(KC)与前置：边界语义、mid更新、何时收缩、停止条件。题目/任务注明主要KC；不追求整门课一次建完知识图谱。

先复用已有证据；只对会改变下一步的未知前置给小诊断。区分能解释、能执行、能选方法、能在新表征使用，缺哪项补哪项。不用看完/熟悉代替目标表现，不要求所有人从零重做。

## 2. 选择支架起点

| 已见情况 | 下一动作 |
|---|---|
| 用户要先自己写/想一道完整题 | 给完整任务与必要规格，等待真实尝试；不先泄露答案 |
| 初学且前置不稳、独立尝试无入口 | 检查最早缺口，使用一个独立示例讲清目标、选择理由和步骤；别示范其待提交稿 |
| 能读懂但不能生成下一步 | 可用补全/解释步骤，随后减少给出的部分；不默认反复填空 |
| 能独立完成当前任务 | 撤掉多余指导，选择一项有目的的变式或延迟检查；不硬走三段式 |
| 会同套路但换表述失败 | 对比条件与选方法依据；查读题/记号/执行/前置/迁移，未诊断不直接重讲概念 |

示例与问题交替、从完整示例到少步骤提示再到独立应用，是可选支架。一次聚焦一个实际缺口；复杂机制首讲可按用户偏好完整展开因果链与数值例，之后再安排本人作答。不是每个单元都必须按同一序列走完。

## 3. 提示分级与渐隐

提示按信息量记为：`无关键提示 → 指向检查位置/条件 → 方法/子目标提示 → 下一步或部分解 → 完整独立示例`。这是本套件的记录约定，不是经过验证的统一认知量表。

- 出题后先等待；卡住时问一句已尝试到哪，给能恢复推进的最小帮助。已明确缺口可直接补，不让用户无效猜语法/API。
- 一次只加所需帮助，不在“提示”里偷偷给最终答案。给下一步后让学习者解释并继续；记录本题**最高帮助**，不能因最后一步独立就洗成整题独立。
- 能自行指出理由/推进时，下个可比任务减少已给信息；不能推进则恢复必要支架并定位前置，不按答错次数机械升降。
- 带帮助答对只支持带帮助完成。用未泄露答案的新任务、无关键提示检验独立性；随后有真实时间间隔的变式才支持保持/迁移。
- 用户明确要求完整解释、或长期卡住无进展，可给完整的独立示范并标注示范；不把它算作本人完成，也不为坚持引导而无限拖延。

## 4. 例子、表征与反馈

起步选择能突出原理的具体数值/小例，指出与定义的对应及类比失效边界。图、代码、公式、文字按任务与可接受方式选，避免同时堆无关信息；拒绝的类比立即停用。不据此给人贴视觉型/左右脑型标签。

学习者尝试后反馈：哪一步成立 → 当前缺口及依据 → 下一次可改的一步。事实/API可直接校正；概念/策略要给理由与自我修正机会。反馈先保证有用与清晰，不声称存在适用于所有任务的最佳延迟。不把对人的称赞或惩罚当作错误诊断。

## 5. 变式与迁移检查

先换一个与目标相关的特征（数值、边界、输入表示、条件），逐步查方法选择与组合应用。掌握基础后再混合易混淆类型，要求说明为何选此方法。交错练习不是随机切换无关课程，也不等于示例与习题交替。

例：二分查找当前题独立正确后，换成“重复值/不存在/最左边界”检查不变式，再用另一种合法区间约定检查理解。若失败，先确定是边界记号变了、没选对方法还是更新条件错；不直接撤销所有已有证据。未出现延迟检查就标待检查，不伪造保持结果。

## 依据与采用范围

[IES (2007) 完整实践指南](https://ies.ed.gov/ncee/WWC/Docs/PracticeGuide/20072004.pdf) 推荐在学习过程中交替示例与解题并随熟练减少示例；指南对不同建议给出不同证据等级，不能说全都同样强。它不要求本套件的五级提示、完整任务起手或代码三段式；这些是结合用户偏好与开源提示结构作出的设计。

[Agarwal等 (2021) 课堂提取练习系统综述，作者全文](https://pdf.poojaagarwal.com/Agarwal_etal_2021_EDPR.pdf) 支持低风险的提取练习。该综述的情境与地域有限，也未确定唯一最佳反馈时机；不能推广为所有任务统一测验、统一反馈延迟。

[OATutor](https://github.com/CAHLR/OATutor/tree/e24c8456e5f75c07b6048159ea9e128b036f673d) 的 `HintSystem.js` 分别管理提示解锁/子提示与作答，启发我们区分给过的帮助与作答结果。此处是方法改编，没有接入其引擎、日志服务或求助惩罚规则；不能拿其研究结果证明本套件有效。
