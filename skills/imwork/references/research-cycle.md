# IM Work：科研问题、实验与结论

用于推进科研交付、设计实验或核验研究结论。先读用户指定项目的相关材料与版本；已知信息直接复用。续课由 imteacher 负责；需要按现有工具构筑整个流程时交 imcowork。短文献判断或一页计划只走必要步骤，不强制跑训练、填完整档案或生成论文。

## 1. 把问题与假设写实

确定这次交付是文献判断、研究计划、复现、候选方法验证还是报告。只补会改变下一步的目标、现实预算或关键输入缺口。

- 从实际问题和已核一手来源提炼待解决限制。记录来源、版本、读到的部分及证据位置；摘要、检索片段和未读引用只作线索，不能当作全文已验证。新颖性范围取决于实际检索，未知就保留未知。
- 写一条可被证据否定的假设：改变什么、预期观察到什么、相对什么对照、什么结果会削弱它。保留主要替代解释；不以“让代理给高分”或“一定超过基线”为研究目标。
- 没有可执行条件时，交付有来源和缺口的可行性计划；缺失的数值、实验和引用不得补写成事实。

## 2. 先约定比较规则

正式比较前，保留一个有版本的最小协议：问题/假设、数据来源与版本、样本与划分、预处理、对照、主指标及实现、必要的重复/种子、允许的调参范围、资源预算、停止条件和结论范围。可以引用已有配置，不重复抄写。

- 基线和候选在可比数据、划分、评价实现与合理调参预算下比较。论文数字可作背景；条件不同就列差异，不能直接宣称超越。必要时先复现基线，复现偏差先解释。
- 区分探索、验证和最终测试。用过结果调方法的数据已参与开发；记录所有相关尝试，不能重新命名为独立测试。没有新的独立评估时，结果保留探索性，不靠重复运行恢复独立性。
- 方法、数据、划分或指标发生会影响结论的改变，保存新协议版本及原因；先前结果保持历史身份。只重新核验受影响的比较、消融、图表和声明，不能把旧证据默默归给新方法。
- 按学科和问题缩放：非随机过程不强加种子；定性/文献研究用来源选择、分析过程、反例与解释边界；不把训练网格、统计显著性或一个成功阈值套到所有研究。

## 3. 从小试到足够的证据

先用获准的非敏感小样本检查流程和对照能否运行，保留环境、代码版本、配置、命令、日志与失败。合成数据或缩小数据上的跑通，只证明相应流程；小试结果不自动支持全数据、泛化或新颖性结论。

| 观察 | 下一步 |
|---|---|
| 基线/评价本身不可靠，或输入不满足协议 | 先定位数据、实现或条件差异，暂不比较方法优劣 |
| 结果值得继续且预算允许 | 按预定比较规则扩大验证；需要额外算力、费用或数据时先按现有授权处理 |
| 存在可定位的实现问题 | 在剩余重试次数内修正，记录改动和新运行，不挑出最好一次掩盖其他尝试 |
| 不支持假设、证据矛盾或预算耗尽 | 交负结果、局限或证据不足；提出最有信息量的下一步，不无限循环到成功 |

涉及机制或组件贡献的主张，用必要的消融、对照或反例区分增益来源。报告预定重复中的差异和失败；样本不够就说明，不伪称显著。探索多种方案后的最好值须带选择过程与适用限制。

## 4. 交付前四项核对

1. **数字与产物。** 关键数值对回原始输出和计算/绘图脚本；按实际执行范围复跑或回算。未复跑明确写明，图表附对应数据、协议与代码版本。
2. **协议与评价。** 核对任务规则、划分、指标、开发/测试用途与对照；不能改评价器或筛掉失败来制造提升。审查也检查负结果与相反证据。
3. **引用。** 核对作者、题名、年份/版本和支持的原文位置。只读摘要就标摘要；未取到原文的关键论据保留待核，不用代理自报替代查证。
4. **方法与代码。** 说明中的方法、实际执行配置、消融、图表与结论必须属于对应版本。改方法后沿依赖检查旧证据；代理审稿是批评线索，不能替代证据审查或现实会议决定。

需要独立复核或多智能体协作时遵循 imcowork 的当次预览与授权；单会话的第二遍检查只称自检。预算到限仍未通过，就如实交待验项和可审查产物。

## 最小记录与结论

持续研究复用项目任务单；只保存会影响复核和下一步的信息：

`问题/假设 → 协议与输入版本 → 运行/失败及真实命令 → 产物指针 → 核验范围 → 下一步/停止原因`

报告中让每个关键声明能对应到：**声明、支持证据与版本、反例/局限、状态**。状态可为支持、削弱、证据不足或待核，不把“跑通”“能复跑”“研究结论受支持”合并。

例：候选小样本随机划分得 83.1%，论文官方划分得 81.2%。当前只能报告本次观察与条件差异；先统一可比条件，再判断提升，不能写“超过 SOTA”。

有价值的流程调整按 [个体适配](adaptation-loop.md) 做可撤回提案，只在获准项目正本保存必要经验；不会自动改变全局技能或其他项目。

## 依据与适用限制

[ScientistTwo §3–4](https://arxiv.org/html/2609.19644v1) 提供分阶段实验、消融、有限迭代与完整性检查的参考；其 AI/ML 基准及自动审稿结果不证明 IM 的科研成效，也不等于实际录用。这里的通用协议、停止条件和记录方式是 IM 的工程适配。
