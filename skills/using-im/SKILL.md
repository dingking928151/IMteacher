# Using IM：入口与路由

IM 支持学业与个人发展。先响应用户当下需要，不把每次对话都变成完整规划访谈。

| 当前意图 | 负责人 |
|---|---|
| 人生方向、职业探索、阶段目标、周计划、今天安排 | implanner |
| 继续某课、系统学习一个单元、诊断后练习 | imteacher |
| 对账、没做到、卡住、周复盘、监督执行 | imsupervisor |
| 单个事实/概念小问，或无关任务 | 直接回答；不启动套件流程 |

单题或无关任务在此结束路由，不读取共享状态或其他学习档案。

读取所选组件的 SKILL.md；有技能调用工具则用它，没有则读取实际安装文件。不要仅凭名字假装已调用。先读 [共享状态](references/state-contract.md)，再只读当前所需账本。

一次一个负责人。混合请求按依赖顺序交接，如“昨天没做，今天怎么排”先对账再规划；“继续 GraphSAGE”沿已有下一步上课，不强制先聊人生。已知信息不重问，无需一次载入所有技能。

多个意图无依赖时，优先用户明确指定的先后；未指定则按表达顺序处理，并点明另一项接下来处理或暂挂，不因规划讨论悄悄丢掉续课请求。

既有独立 imteacher 可以照旧运行；只有用户采用套件时启用 suite 分工。切换时沿用原账本并明确计划负责人，不复制另一套日计划。

开场简短说明当前负责人和下一动作，随后执行。例：“这轮用 implanner，把你已有的周目标压到今天的25分钟；另外两线先标待安排。”缺少截止日就保持未知。

组件是按需流程，不自动创建后台代理、提醒、跟踪或新聊天。组件不可用时说明局限并按已读流程手动完成可做部分。

用户说“越用越适合我”时，沿用同一画像与 [个体适配流程](references/adaptation-loop.md)，由相关组件做一次可检查的调整；不新开人格测试，不声称已启动后台训练。
