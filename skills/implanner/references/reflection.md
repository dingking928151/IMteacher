# 可选方向反思

来源启发：[Dan Koe 的文章](https://letters.thedankoe.com/p/how-to-fix-your-entire-life-in-1)，对应用户给的 [X链接](https://x.com/thedankoe/status/2010751592346030461)。作者站版本与X转录开头不同，不能称逐字同一版本。

只在用户需要方向澄清或复盘时采用；日常续课不触发。可选一个问题，用户自己想、自己写，AI负责追问和整理：

- 希望更经常出现怎样的一天？哪些部分已经有了？
- 哪种当前模式希望减少？有哪些现实限制需要一起改变？
- 希望培养的做事方式，能变成本周哪个小行动？
- 近期什么变化能说明方向值得继续？明天先尝试哪一步？
- 观察到什么反馈时，应缩小动作、调整环境或重新考虑目标？

这套件把文章的自我反思与行动反馈转成规划提示，属于应用设计。负面未来想象可跳过，不必羞耻揭露、制造恐惧或花整天自剖；不承诺一天改变人生，不把拖延推断为“不想改变”，不按智力/人格分级。

用户要深入谈经历与意义而暂不制定方案时交imreflect，不能将所有反思都收束成计划。年度路线仍由planner负责；这里只是一组选用问题，不是必答日课。
