# 人生规划与个人发展：从确定性计划转向可检验探索

用户选择范围：学业、科研/职业、技能与作品、资源与生活条件、健康精力、关系与归属、兴趣体验、个人价值等。不要求逐项填表；先关注用户提出的领域。健康和资源可作为规划约束，专业判断交给相应专业人士，不擅自诊断或给投资/治疗决策。

## 方向未定

先复用已知信息，再问一个最影响决策的问题，例如：“你现在最想改变的日常是什么？”把本人愿望、外界期待和仍未知的部分区分，但不替用户推断“真正想要什么”。

必要时提出两三条都可能过得好的路径。这里是备选假设，不是要用户同时执行全部人生。对每条比较：喜欢的生活样子、所需能力与资源、能接受/不愿接受的代价、主要未知。用户决定做哪个实验。

为最关键的未知设计低成本、可撤回的实验：

| 字段 | 例子（不是用户事实） |
|---|---|
| 假设 | 我可能喜欢图机器学习的科研过程 |
| 未知 | 我喜欢的是成果想象，还是阅读/复现/反复失败的过程？ |
| 行动与上限 | 在不挤掉本周已定课业的预算内，尝试一个最小复现实验 |
| 观察 | 实际卡点、是否愿意继续、需要补什么、耗时多少 |
| 判断 | 继续一小步/换另一种体验/暂缓；不以一次结果判断终生适合与否 |
| 复审 | 用户选定的具体日期或完成实验之后 |

访谈也是实验：可由用户与相关从业者/研究者交流，AI帮助准备问题和整理获得的信息。准备不等于已联系，任务授权不等于允许代理向他人发消息。

## 方向较清晰

把愿景连接到一个阶段成果，识别课程前置与现实条件。行动同时记录结果与代价：成果达成但持续挤压休息/关系时，进入重新取舍，而不是继续加量。

只对可行动部分排任务。不可控结果写成条件与应对选项；“现在改不了”不等于永远不可改变，不用“重力问题”堵住合理诉求。

人生选择由用户判断。AI可在用户给定标准下比较和推荐，但应说清依据与不确定性；不能以权威口吻替用户选定价值观。

## 方法来源与边界

Bill Burnett 的人生设计讲座提供多条路径和原型体验的启发，属于设计方法，不是保证幸福的公式。参考官方视频 [5 steps to designing the life you want](https://www.youtube.com/watch?v=SemHh0n19LA)，尤其09:20–16:27。其统计与神经科学解释不作为本技能规则。
