# 留痕系统 · 文件模板与更新时机

留痕 = 跨会话续接的唯一载体。学习者可以换会话、换时间回来，
新会话读留痕即可无缝续教。**每轮批改必须同步更新留痕**。

## 文件位置与命名

- 放在学习资料同级目录，如 `教案目录/学习留痕_W1-W8/00_学习进度总览_W1.md`
- 一个教学阶段（一周/一单元）一个文件；阶段间可互链

## 模板结构

```markdown
# W? 学习留痕 · 进度总览

> 开始日期：YYYY-MM-DD
> 教学方式：IMteacher（teach-check-continue + 代码三段式 + 实敲模式）
> 目标：一句话写明本单元毕业标准

---

## 一、知识地图

### 主线
- [ ] 1. 知识点 A（一句话内容）★核心★ 标注
- [ ] 2. 知识点 B

### 副线
- [ ] A. 副线内容 ← 教学顺序/备注
- ~~X. 已裁定搁置项~~ —— 用户裁定：搁置原因（裁定保留在案，不删）

## 二、资料清单与对账（资源 × 看哪里 × 回来对什么账）

- PPT/讲义考点清单：开课时从用户提供的教案/PPT 提取考点建账，覆盖一个勾一个（每周小测出题源）

## 三、前置对账与模式记录
- 已确认的前置能力
- 实敲/纸面模式及切换记录

## 四、检查点流水（每轮追加）

### 检查点 N（知识点名）—— 日期
- 逐题结果：✅/❌/半对 + 学习者原答案摘要 + 错误分析
- 处理：重讲要点 / 读法 / 迷你验证 / 勘误
- 判定：通关 → 下一站

## 五、勘误记录（教案/资料不严谨处，含修正版）

## 六、收官盘点
- 板块 × 状态总表
- 剩余实做项（与教学线分开记账）
- 隐藏收获（调试工具/论文读法等 meta 技能）

## 七、错题池（滚动回顾出题源）
- 每条：考点 | 当时的错法 | 连对计数 | 下次变式方向
- 出池：同一考点连续两次答对（跨时间、换问法）

## 八、每周小测成绩单
- 日期 | 逐题对错 | 薄弱点 | 补测安排
```

## 更新时机（缺一不可）

| 时机 | 更新什么 |
|------|---------|
| 开单元 | 知识地图 + 资料清单 + PPT/讲义考点清单 + 模式记录 |
| 每轮批改 | 检查点流水（原答案 + 判定 + 处理）——**学习者原话要记**，错误分析靠它 |
| 发现教案不严谨 | 勘误记录 |
| 学习者裁定搁置/删除 | 在知识地图上划线保留裁定与原因，不物理删除 |
| 知识点/副线通关 | 勾选 + 日期 + 通关证据（如"14 错→1 标点"） |
| 单元收官 | 收官盘点 + 剩余实做项 |
| 每次滚动回顾后 | 回顾一行（抽了什么/对错/出池没）+ 错题池计数 |
| 每周小测后 | 小测成绩单 + 错题池更新 |

## 新会话续接流程

1. 读留痕文件（老会话也可能要读：上下文压缩后留痕是 ground truth）
2. 信任已通关项（不重考），从第一个未完成项继续
3. 若留痕与学习者口头描述冲突，以留痕为准并当场对齐
4. 检查点流水中"高发错误"名单决定新检查点的重复覆盖点
5. 开课第一步：滚动回顾 2-3 题（错题池必抽 + D-1/D-3/D-7 到期项），过完再进新课

## 语气与隐私

- 留痕是教学档案，记录错误分析对事不对人；不用评价性语言（"粗心""笨"），
  只记现象与根因（"第 2 次仍混淆 fd 与 inode，根因：三层楼未分层"）
