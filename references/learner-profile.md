# 学习者画像 · 机制与模板

画像 = **教学法账**（怎么教这个人最有效），与留痕（**知识账**：学到哪了）分工：

- 留痕回答："学到哪了、错题池里有什么、还欠什么"
- 画像回答："用什么类比一讲就通、什么讲法翻过车、他的病灶规律与已验证疗法、
  几小块后要串讲、CP 难度带在哪"

为什么需要：同一学习者的教学资产（有效类比、失效讲法、错误模式）若只散在留痕里，
换单元、换会话就靠运气存活。画像让教学法经验跨单元**复利**——这就是成长性。

## 文件位置

- 与留痕同级：`<教案目录>/00_学习者画像.md`（一个学习者一份，跨单元持续更新）
- 若有 Claude Code memory：memory 里只放一行指针，正本放画像文件

## 初始化（无画像时，开单元第一步）

三源搜集，按信度排序：

1. **历史留痕**（最可靠）：扫检查点流水的错误分析、勘误记录、有效类比的痕迹
2. **memory / 已有档案**：学习背景、环境、既定规矩
3. **开场访谈**（补缺）：直接问 3-5 个问题——
   - 在学什么/学过什么（定位可用锚点：新类比优先从已学课程里取材）
   - 哪种讲法让你开窍过、哪种让你睡着（自评偏好，待观察验证）
   - 出错时通常卡在哪层：符号 / 概念 / 代码结构（学习者常说不清，第一单元以观察修正为主）
4. **首课观察**（初始化后 2-3 轮课）：验证/修正自评——**自评常不可靠，以实测为准**

## 模板结构

```markdown
# 学习者画像 · <名字/代号>

> 建立日期 | 版本 | 数据源

## 1. 锚点库（讲新东西挂哪里）
- 已验证有效：<类比A>（何时验证）……
- 已验证失效：<讲法>（何时翻车）——失效记录与有效同等重要，防止换会话后重用翻车讲法
- 可用学科锚：<已学课程/技能清单>

## 2. 病灶库（错误模式 → 已验证疗法）
| 病灶模式 | 实例 | 有效疗法 |

## 3. 节奏与形式偏好
- 小块阈值：几小块后需要全景串讲
- CP 难度带：过易→敷衍；过难→挫败；当前校准
- 提问信号：什么问法 = 深挖信号，当堂优先处理
- 时段/频率特征

## 4. 动机与态度
- 有效的正反馈机制、坦白/诚信文化状态、值得强化的自主行为

## 5. 更新流水（只追加）
- 日期 | 新发现 | 类型（锚点/病灶/节奏/动机）
```

## 更新规则（防膨胀）

- **只记影响教学决策的信息**：能改变"下节课怎么讲"的才写；纯知识进度不写（那是留痕的事）
- 病灶必须带**已验证疗法**才入库；只出现一次的错不建条目（等复发再建）
- **失效类比同样入库**——防止换会话后重用翻车讲法
- 每次更新追加流水一行；画像正文 ≤60 行，膨胀时合并同义项
- 使用时机三刻：开课读一遍（1 分钟）；批改后回写；用新类比/新讲法前先查库
