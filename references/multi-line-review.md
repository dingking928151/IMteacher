# 多线并行 —— 对话分工 · 盘点模板 · 每日时间预算

一个学习者常有多条线并行：学校课业线、算法竞赛线、语言线、科研线、日常习惯线…
本规程堵三个事故源：**盘点漏线、对话抢课、时间糊涂账**。

## 一、线与对话的分工

- **一线一对话一文件**：每条线一个专属对话 + 一份 `00_学习进度总览_<线名>.md`。
  线内进度只记自己的文件——文件是对话间唯一的交接载体（跨对话续接 = 读对方
  总览，信任已过项，从第一个未过项继续）。
- **不抢课**：本对话只展开本线内容。其他线在盘点中各留一行快照：
  `线名 | 状态一句话 | 归属对话/文件路径`。学习者问及他线细节时，指向归属对话，
  不就地开课。
- **移交指令**：学习者说"这条线去那个对话搞"= 正式移交。动作：①对方总览文件
  头部补移交注记（日期+范围）②本线总览记一笔 ③此后本对话对该线只留快照。

## 二、大纲盘点六节模板（固定顺序，漏一节=不合格）

适用场景：学习者问"进度到哪了/怎么样了"、单元收官、开周盘点、考试前对表。

```markdown
### 盘点 · <日期>
1. 本线地图 —— 勾选状态+日期（从总览文件抄，禁止凭记忆重构）
2. 他线快照 —— 每线一行：线名 | 状态 | 归属
3. 日常线 —— 日课/Anki/滚动回顾等固定项：当日发生没有（没发生=点名补）
4. 挂起线 —— 暂停项 + 重启条件，一行一个
5. 时间预算 —— 本周每线每日分钟数 + 今日实际投入（差额>50%要说明）
6. 硬日程 —— 考试/截止日 + 剩余天数
```

## 三、每日时间预算

- **开周定表**：`线 × 每日分钟`，写进本线总览的"时间预算"节。示例：

| 线 | 归属对话 | 每日分钟 | 说明 |
|---|---|---|---|
| 考试专项线 | 本对话 | 90-120 | 加权主线 |
| 其余学习线 | 各自对话 | 20-30 保底 | 降载不停摆 |
| 日常线 | 任意 | 25-30 | 不断（日课/Anki/回顾） |
| 挂起线 | — | 0 | 重启条件写明 |

- **加权规则**：考试/截止日前 7 天，该线每日分钟上调，其余学习线降载到保底；
  日常线保持不全断（抗遗忘机制停一周，恢复成本远大于每天 25 分钟）；挂起线保持 0。
- **预算 ≠ 排班**：预算是投入量目标。学习者当日实际投入记流水；连续 3 天偏离
  >50%，主动提议调表，不硬扛原表。
- **考后恢复**：降载线复原原预算；先补滚动回顾/错题池欠账，再开新课
  （欠账不过周）。
